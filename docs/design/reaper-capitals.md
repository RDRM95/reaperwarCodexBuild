# Reaper silhouettes — v0.12

Original procedural fan models. Sovereign-class capitals retain six swept mechanical arms and a layered forward hood, with a slender ridged body tapering aft. Destroyers retain four wider-set legs and a compact body. Harbinger has a broader spined hood and amber eye/seam illumination; ordinary Reapers retain crimson light and blue-black graphite plating.

Rendering was undersized relative to existing simulation hulls. Overall mesh length, muzzle and glow nodes are now transformed together to the catalogue: Sovereign 2,000 m, destroyer 160 m, Harbinger 2,400 m. Harbinger's value is an existing simulation estimate, not a canonical claim. This does not alter hull integrity, collision radii or weapon balance. The separate chart proposal in SCALE_REFERENCE remains reference material, not an automatic replacement for catalogue data.

Tests compare actual mesh bounds with those dimensions and check that building Harbinger does not recolour shared ordinary-Reaper materials. Remaining limits: no articulated walking/arm animation or exact screen-model likeness.
